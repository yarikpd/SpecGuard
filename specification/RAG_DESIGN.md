# Проект RAG — утверждено

RAG обязателен. Рекомендация для проверки: гибридный поиск по смысловым единицам требований с сохранением иерархии и раскрытием явных ссылок. Сравнивать его с векторным поиском на одинаковых эталонных данных и бюджетах; GraphRAG и reranker не включать без измеренной пользы.

Сохранять исходный документ, фрагмент, идентификатор, раздел, условия, исключения, явные связи и происхождение извлечённого представления. Автоматическое извлечение — интерпретация, а не изменение ТЗ. Разбиение не должно отделять условие от исключения без возможности восстановить контекст. Разбор PDF, DOCX, Markdown и TXT проверять отдельно; сканы не входят в первую версию.

Запросы строятся по выбранному ТЗ, краткому пояснению пользователя, изменённому поведению, именам, путям, идентификаторам и сквозным требованиям. Классификация сквозных требований — дополнительный канал, а не исключающий фильтр. Связи из документа отличать от гипотез модели. Пустой результат поиска не доказывает неприменимость требования или отсутствие нарушения.

Каждый запуск закрепляет конкретное состояние документов и индекса. Текущая база ТЗ может обновляться; материалы прошлых запусков сохраняются без пользовательского механизма версий. Недоступный или частично разобранный документ не считается пустым. Обновление индекса не должно смешивать состояния. Embeddings создаёт модель через отдельно настраиваемый OpenAI-совместимый API, локальный или внешний; исходная модель выбрана, а выбор хранилища и порогов качества открыт. Изменение embedding-профиля требует совместимого нового индекса; смена текстовой LLM не меняет embedding-модель.

## Кандидаты для исследования
Пользователь выбрал исходный вариант Qwen3-Embedding-0.6B через Ollama для последующей проверки с OpenAI-совместимым API с явным тегом и фиксацией digest, квантования, размерности, нормализации и шаблонов запроса. Альтернативы — EmbeddingGemma 300M и BGE-M3. Реальная память, swap, скорость и качество локального примера на M5/16 ГБ не измерены. Внешний embedding API получает отправленные ему фрагменты и запросы. Гибридный поиск включает отдельный лексический канал. Нужно исключить скрытое усечение: [API Ollama](https://docs.ollama.com/api/embed) по умолчанию может усекать текст. Источники: [Qwen](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B), [Ollama Qwen](https://ollama.com/library/qwen3-embedding), [EmbeddingGemma](https://ai.google.dev/gemma/docs/embeddinggemma/model_card), [BGE-M3](https://huggingface.co/BAAI/bge-m3). Модели не устанавливались.
