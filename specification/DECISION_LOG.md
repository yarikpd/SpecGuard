# Журнал решений — утверждено

| Решение | Статус | Альтернативы и основание |
|---|---|---|
| RAG обязателен; GitHub MCP — исходный канал | Утверждено пользователем | Замена MCP требует согласования |
| Проверять нарушения и реализацию требований выбранного ТЗ | Утверждено пользователем | Пользователь выбирает ТЗ и кратко поясняет выполненное; полное описание заданий не требуется |
| Ручной запуск, результат в агенте, чтение кода | Утверждено пользователем | Самостоятельный запуск агентом тестов проверяемого приложения и публикация в GitHub отложены |
| TXT, Markdown, DOCX, текстовый PDF | Утверждено пользователем | Сканы и изображения не требуются в первой версии |
| История сохраняет материалы при перезаписи актуального ТЗ | Утверждено пользователем | Управление версиями ТЗ отложено |
| При неполной выдаче MCP — частичный отчёт | Утверждено пользователем | Ограничение и пропуски показываются |
| Оспаривание с повторным рассмотрением комментария | Утверждено пользователем | Пересмотр использует исходные материалы; новые данные — отдельная проверка |
| Hybrid RAG + иерархия и явные ссылки | Рекомендация | Сравнить с vector RAG; GraphRAG и reranker требуют доказанной пользы |
| Узкий read-only адаптер MCP | Рекомендация | Tree/DAG fallback исключён до проверки соответствия PR diff |
| Фиксация исходных данных запуска и частичного прогресса | Рекомендация | Позволяет разбирать историю; не обещает идентичный ответ модели |
| Замена ТЗ и противоречия документов | Утверждено пользователем | Явный выбор заменяемого документа; конфликты показываются человеку |
| CLI и язык отчёта | Утверждено пользователем | Язык выбирается в CLI |
| Модели | Утверждено пользователем | Раздельные настройки API обеих моделей; embedding может быть локальным или внешним |
| Среда | Утверждено пользователем | Локальный учебный проект, MacBook Pro M5 16 ГБ; бюджет и сроки не заданы |
| Qwen3-Embedding-0.6B через Ollama | Выбрано пользователем; проверка требуется | Проверить совместимость API, retrieval и ресурсы на материалах проекта |
| Официальный GitHub MCP локально через stdio | Выбрано пользователем; проверка требуется | Проверить схемы, права и работу на PR и коммитах |
| Merge-коммит | Утверждено пользователем | Сравнение с первым родителем, его SHA указывается в отчёте |
| Недоступная базовая ревизия | Утверждено пользователем | Частичный отчёт о текущем состоянии без приписывания изменения |
| Тестовый репозиторий | Утверждено пользователем | Подготовить отдельный учебный GitHub-репозиторий и проводить на нём проверки; эталоны вне доступа агента — рекомендация специалистов |

Утверждение комплекта пользователем 29 октября 2026 года не превращает варианты, обозначенные рекомендациями, в уже выбранные реализации; открытые вопросы остаются в OPEN_QUESTIONS.md.

Пользователь уточнил: результаты агента оцениваются им вручную; численные пороги не заданы. Дополнительная политика хранения и ограничения поставщиков не определяются как отдельные требования текущего учебного проекта.
