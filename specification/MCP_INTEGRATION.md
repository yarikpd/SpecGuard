# Интеграция GitHub MCP — утверждено

Предлагается read-only адаптер приложения к GitHub MCP. Он разрешает PR/коммит, получает доступный список изменений, patch и нужные фрагменты кода, фиксирует происхождение и возвращает независимые признаки результата операции, полноты источника и согласованности ревизий. Конкретные схемы выбранного сервера и его совместимость должны быть проверены.

Для PR фиксируются известные base/head и идентичности репозиториев, включая fork; для коммита — SHA и родители. Фрагменты читаются по известным ревизиям; для удалений нужна исходная сторона, для переименований — старый и новый путь. Проверка SHA PR до и после чтения обнаруживает некоторые изменения, но не гарантирует атомарности. Ограничение API, недоступный файл, неизвестный остаток, усечение, ошибка и несогласованность отражаются явно; 404 может означать и недоступность. Нельзя считать пустой patch отсутствием изменений.

Большие изменения обрабатываются по доступным страницам и частям; при ограничении GitHub пользователь согласовал частичный отчёт. Сравнение деревьев и обход DAG исключены из базового решения до проверки семантики PR diff. Для merge-коммита сравнение выполняется с первым родителем; его SHA указывается в отчёте. Первый родитель не обязательно является основной веткой. Запись в GitHub и прямой альтернативный канал не предусматриваются.

Данные репозитория не получают полномочий на действия. Доступ ограничивается разрешёнными операциями; секреты не включаются в сохраняемые материалы анализа. Ошибки и повторы ограничиваются и отображаются; поведение конкретного MCP необходимо проверить интеграционными сценариями.

## Кандидат для локального проекта
Пользователь выбрал официальный [GitHub MCP Server](https://github.com/github/github-mcp-server/blob/v2.0.3/README.md) в локальном процессе stdio, с закреплённой версией и [режимом чтения](https://github.com/github/github-mcp-server/blob/main/docs/server-configuration.md); Docker не обязателен. Исходный набор инструментов: pull_request_read, get_commit, get_file_contents, с проверкой схем и прав. Токен ограничивается независимо. GitHub остаётся сетевым источником. Удалённый сервер — альтернатива. Выбор требует проверки: живые вызовы пока не проводились.

При недоступной базовой ревизии допускается частичный анализ доступного текущего кода. Без сравнительных доказательств нельзя утверждать, что проблема внесена или реализация добавлена выбранным PR/коммитом.
