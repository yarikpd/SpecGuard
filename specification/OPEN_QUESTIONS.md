# Открытые вопросы — утверждено

## Утверждённые ответы
- Агент — локальное CLI-приложение; язык отчёта выбирает пользователь. Пользователь выбирает ТЗ и PR/commit, кратко поясняет выполненное и запускает автоматическую проверку.
- Отдельно настраиваются OpenAI-совместимые API embedding-модели и текстовой LLM; оба API могут быть локальными или внешними. Среда — MacBook Pro M5, 16 ГБ; бюджет, сроки и масштаб не заданы. При внешнем API отправляемые ему данные покидают компьютер.
- Пересмотр замечания использует материалы исходной проверки; новые данные — отдельная проверка. При замене ТЗ пользователь явно выбирает документ, противоречия показываются человеку.
- Merge-коммит сравнивается с первым родителем; при недоступной базовой ревизии допускается частичный отчёт без атрибуции изменения. В ходе реализации создаётся отдельный тестовый GitHub-репозиторий.
- Материалы прошлых проверок сохраняются; управление версиями ТЗ отложено. TXT, Markdown, DOCX и текстовый PDF обязательны; OCR не требуется. При недоступных файлах и ограничениях MCP допускается частичный отчёт.

- Пользователь вручную оценивает результаты работы агента. Численные пороги качества пока не установлены.
- В качестве исходной конфигурации выбраны Qwen3-Embedding-0.6B через Ollama и официальный локальный GitHub MCP. Их работоспособность и качество необходимо проверить; проверки пока не проводились.
- Дополнительные требования к политике хранения и защиты данных и ограничения на внешние API пользователь не установил для текущего учебного проекта.

## Оставшиеся проверки
1. Проверить Qwen3-Embedding-0.6B через OpenAI-совместимый API Ollama на MacBook Pro M5/16 ГБ: запуск, совместимость API, качество retrieval, память и задержку.
2. Проверить официальный локальный GitHub MCP: схемы, права, чтение PR и коммитов, ошибки и ограничения.
3. Провести ручную оценку результатов на тестовых примерах; численные пороги качества не назначены.
